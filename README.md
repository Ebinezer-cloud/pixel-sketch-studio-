## ✨ Overview

**Pixel Sketch Studio** is a lightweight photo-to-art editing application developed using HTML, CSS, and Vanilla JavaScript.

It allows users to upload photographs, apply artistic drawing effects, customize image appearance, compare original and edited images, analyze image properties, and export their creations as PNG images or printable A4 PDF documents.

The application features a modern glassmorphism interface with a pink, blue, and silver color theme.

## 🚀 Features

### 🖼️ Image Upload
- Upload images directly from your computer.
- Drag-and-drop image support.
- Automatic image orientation detection.
- Instant image preview.

### 🎨 Artistic Effects

Choose from four built-in artistic effects:

| Effect | Description |
|---|---|
| Sketch Drawing | Converts photos into sketch-style artwork. |
| Pencil Drawing | Creates a pencil-drawing appearance. |
| Blood Drawing | Applies a red-toned artistic drawing effect. |
| Cartoon Pencil | Produces cartoon-style artwork with outlined edges. |

### 🎛️ Image Customization
- **Intensity:** Adjust the strength of the selected effect.
- **Detail:** Control drawing details and edge appearance.
- **Paper Grain:** Add a paper-like texture to the artwork.

### 🔄 Before & After Comparison
- Interactive comparison slider.
- Original image preview.
- Edited image preview.
- Easy visual comparison.

### 📄 A4 Page Settings
- Portrait orientation.
- Landscape orientation.
- Fit whole photo.
- Fill page.

### 📊 Image Analytics

Analyze original and edited images using:

- Brightness.
- Contrast.
- Saturation.
- Edge density.
- Unique colours.
- Brightness histogram.
- Rendering time.
- Edit history.

### 💾 Export Options
- Download edited artwork as PNG.
- Export artwork as A4 PDF.
- Reset editing settings.
- Maintain printable A4 page dimensions.

## 🛠️ Technologies Used

| Technology | Purpose |

## ⚙️ Installation & Setup

No installation or additional dependencies are required.

**Step 1:** Download or clone the repository.

```bash
git clone https://github.com/Ebinezer-cloud/pixel-sketch-studio.git
```

**Step 2:** Open the project folder.

```bash
cd pixel-sketch-studio
```

**Step 3:** Open `index.html` in your browser.

You can also simply double-click `index.html`.

**Step 4:** Upload an image and start creating artwork!

## 💻 System Requirements

- Windows, macOS, or Linux.

- No backend server required.

## 🔒 Privacy

Pixel Sketch Studio processes images directly inside the browser using JavaScript and the HTML Canvas API.

There is no application backend or image-upload server in this project. Your images are processed locally in the browser.
